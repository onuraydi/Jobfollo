# Update docs

1. Compare the change against `docs/PRD.md` and `docs/ARCHITECTURE.md`.
2. Update any statement that is now wrong. Do not add speculative content.
3. If a design decision was made or changed, append an entry to `docs/DECISIONS.md` (context, decision, consequences).
4. Update checkboxes in `docs/ROADMAP.md`.
5. List the doc changes you made.
